## openfga.dev/project
- "It was originally developed by Auth0/Okta, open sourced in June 2022, and donated to the Cloud Native Computing Foundation." "OpenFGA was created by the Auth0 FGA team with support from Auth0 Labs and Auth0's Office of the CTO." Inspired by Google Zanzibar.
- Site offers an OpenFGA agent skill (github.com/openfga/agent-skills) and a docs MCP server (kapa.ai) — documentation helpers, not an authorization MCP feature.
