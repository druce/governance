## AI Network Firewall — 2026-07-30 (Redwood City)
- Delivered "as part of Check Point firewall software release R82.20" from "the physical or virtual firewalls customers already operate".
- Employee AI use: "Discover AI apps, agents, and tools in use — both shadow and sanctioned"; can "stop sensitive data from leaving the network based on the prompt's use case".
- AI tools: "Discover Model Context Protocol (MCP) communication, gain full visibility into servers and used tools".
- AI apps/LLMs: "Prevent prompt injection and adversarial inputs, blocking malicious prompts before they reach the LLM."
- Part of the "AI Defense Plane", "a unified control plane for discovering, governing, and protecting AI across the network"; other enforcement points: standalone API, endpoint agent, containerized firewall for AI data centers, WAF. "available now." Lakera not named in the release.

## Harmony DLP solution brief
- "Check Point Endpoint and Browser Data Loss Prevention (DLP)" / "Check Point Harmony Data Loss Protection (DLP)", part of the Harmony workspace security suite.
- Prevents sensitive data exposure across "endpoints, browsers, web applications, and GenAI tools"; "prevents sensitive data submission, blocks copy-pasting of confidential information"; "AI-powered classification ... in GenAI applications." Search coverage: 700+ predefined data types; works across Harmony Endpoint, Harmony Browse and Harmony SASE.
