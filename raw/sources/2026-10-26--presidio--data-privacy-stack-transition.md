## Facts
- Blog post "The Presidio Project Joins Data Privacy Stack" — "Last updated: Jun 29, 2026" (no separate announcement date). Says Presidio "moves to its new home under Data Privacy Stack, an independent, community-driven organization"; "We're deeply grateful to Microsoft for supporting Presidio..."; "Presidio remains open source under the MIT license"; transition "should be largely seamless" for existing users.
- Post does NOT say whether Microsoft still employs maintainers or sponsors the project.
- GitHub: `microsoft/presidio` now resolves to `data-privacy-stack/presidio` (repo created 2018-05-04; MIT; ~11.5k stars; pushed 2026-10-26). The data-privacy-stack GitHub org was created 2026-04-13; repos: presidio, presidio-research, website, MVG.
- Governance: "Minimum Viable Governance" (GitHub's MVG template) — a Technical Steering Committee + per-project maintainers, consensus-based. Initial TSC: Omri Mendels, Nava Vaisman Levy, Sharon Hart, Coby Peled, each listed with affiliation "Presidio Maintainer"; TSC members serve "not as representatives of any employer or vendor organization."
- Charter: org "does not govern any trademark ... No trademark for the Presidio name currently exists under this organization." No legal entity/foundation named.
- Website moved: microsoft.github.io/presidio -> data-privacy-stack.github.io/presidio -> presidio.dataprivacystack.org. Contact presidio@dataprivacystack.org.
