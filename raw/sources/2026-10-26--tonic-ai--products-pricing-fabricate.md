## Homepage (2026-10-26)
- Tonic Fabricate: "Synthesize relational data, free-text, and mock APIs from scratch"

## Pricing page (2026-10-26)
- Fabricate: Free $0/mo ($5 credits); Plus $29/mo ($25 credits) + pay-as-you-go token usage; Enterprise custom, Tonic Cloud or self-hosted, SSO/RBAC.
- Structural: Professional (custom; up to 10TB source data, 10 users, Tonic Cloud); Enterprise (custom; unlimited; Tonic Cloud or self-hosted). Annual contracts priced by plan and size of connected source data.
- Textual: pay-as-you-go flat rate per 1,000 words (no figure shown); Enterprise custom, cloud or self-hosted; AWS Marketplace AMI and Snowflake Native App.
- Ephemeral not on pricing page.

## Fabricate acquisition press release (2025-04-22)
- Tonic.ai acquired Fabricate, built by Mockaroo; Mockaroo founder/CEO Mark Brocato joins Tonic to lead it. Price undisclosed.
- Fabricate generates relational data from schema definitions, SQL, or natural-language prompts; "purpose-built for greenfield development".
- Boilerplate: founded 2018; HQ San Francisco; offices Atlanta, New York, London; "hundreds of customers" incl. eBay, Cigna, American Express, Volvo.

## Tonic Ephemeral (vendor blog/guides via search)
- Databases-on-demand: empty DBs or DBs populated from data snapshots (typically Structural output); expiration timers; API/CI-CD driven; uses cloud volume snapshots (EBS on AWS).

## Textual MCP server (2026-03 blog; docs)
- Open-source MCP server (npm @tonicai/textual-mcp; GitHub TonicAI/textual-mcp) exposing Textual redaction tools (redact_text, redact_json, redact_html...) to MCP clients; needs a Textual instance (cloud or self-hosted).
