## Facts

- **Rebrand**: Bedrock Security announced its rename to **Bedrock Data** on
  **2025-08-05**. Press release headline: "Bedrock Security Rebrands as Bedrock Data
  to Advance Data Governance, Security and Management in the AI Era."
  Direction is unambiguous in the headline itself: Security is the OLD name,
  Data is the NEW name.
- **Legal entity**: **Bedrock Labs, Inc.**, doing business as Bedrock Data
  (stated in the vendor's own site footer/press material). The legal entity name
  did not change — this is a DBA/brand change, not a new company.
- **HQ**: Menlo Park, California — unchanged from the Bedrock Security era.
- **Leadership**: **Bruno Kurtic, CEO and co-founder** — the same person named
  CEO of Bedrock Security in the 2024-07-23 BusinessWire release
  ("Bedrock Security Names Co-Founder Bruno Kurtic as New Chief Executive Officer",
  https://www.businesswire.com/news/home/20240723928182/en/Bedrock-Security-Names-Co-Founder-Bruno-Kurtic-as-New-Chief-Executive-Officer).
  Continuity of CEO across both brands confirms same entity, not a domain squat.
- **Product continuity**: the patented **Metadata Lake** — announced under the
  Bedrock Security name ("Bedrock Security Launches Industry-First Metadata Lake",
  still hosted at bedrockdata.ai/news/) — is the same flagship technology the
  Bedrock Data site leads with today ("Beyond DSPM", Metadata Lake + ArgusAI).
  The vendor migrated its own historical Bedrock Security press releases onto the
  bedrockdata.ai newsroom, which is itself evidence of a single continuous entity.
- **Domain**: `https://www.bedrock.security` **301-redirects to `https://bedrockdata.ai/`**
  (verified by curl, 2026-07-27). The vendor controls both domains.
- **Rationale quote (Kurtic)**: "At its core, data security is a data management
  problem. If you don't know what data you have, where it lives, who owns it or how
  it's being used, you can't secure it or use it effectively." The rebrand widens
  positioning from security-only to data governance + security + management.

## Not-a-different-company check

Ruled out the "unrelated company at the redirect target" hypothesis on four
independent points: (1) the rebrand press release is a first-party announcement
carrying both names in one headline; (2) same CEO/co-founder Bruno Kurtic;
(3) same HQ (Menlo Park); (4) same patented Metadata Lake product and same
historical press archive. Confidence: **high**.

## Name-collision hazard (unrelated homonym)

An **unrelated** company also called "Bedrock Data" existed at **bedrockdata.com**
(note `.com`, not `.ai`): a Boston-area, .406 Ventures-backed SaaS **data-integration**
vendor whose product **Fusion** synced customer data across Salesforce/NetSuite/Marketo/
HubSpot etc. Active at least 2016–2018 (PRNewswire 2018-05-21, "Bedrock Data's Fusion
Expands to More SaaS Systems"; .406 Ventures launch coverage for Fusion).
Different domain, different product (CRM/marketing data sync, not data security),
different investors. Current status not verified — no evidence found either way of
wind-down or acquisition. Not the entity described on this wiki page; flagged so future
searches for "Bedrock Data" don't conflate the two.
