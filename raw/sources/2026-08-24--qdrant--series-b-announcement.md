## Round

- **Announced 2026-03-12. $50M Series B, led by AVP** (Advance Venture Partners).
- Participating: Bosch Ventures, Unusual Ventures, Spark Capital, 42CAP.
- Follows a $28M Series A (2024); total raised ~$87.8M (per TechTarget coverage,
  https://www.techtarget.com/searchdatamanagement/news/366640132/).

## Product / traction

- Open-source vector search engine written in **Rust**; core repo **Apache 2.0**.
- 250M+ package downloads, ~29,000 GitHub stars.
- Product line: Qdrant Vector Database (OSS), Qdrant Cloud (managed), **Qdrant
  Hybrid Cloud** (data plane in the customer's own infrastructure), Qdrant Edge
  (beta), Qdrant Serverless (announced as coming).
- Named customers: Canva, Bazaarvoice, HubSpot, Roche, Bosch, OpenTable.
- Positioning: "composable vector search" — dense/sparse vectors, metadata
  filtering, edge-to-datacenter deployment.
