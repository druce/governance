# Obot — editions and licensing (docs)

- URL: https://docs.obot.ai/enterprise/overview
- Fetched: 2026-10-20
- Good for: what is free vs paid, user/device caps, how licence keys work, Obot Cloud. Vendor docs.

- "Every edition runs the same MIT-licensed code from the same container image." "The editions differ only in their license key."
- Obot Community (no key): self-hosted, free, up to 100 users / 100 devices; MCP gateway and registry, LLM gateway,
  skills registry, Device Management; Local, GitHub, Google auth; no support.
- Registered Community: free registration; adds Entra, Okta, JumpCloud, Auth0; same 100/100 caps; no support.
- Obot Enterprise: self-hosted, contact sales; "removes the user and device limits (unless your contract sets
  specific limits)"; enterprise auth; support.
- Obot Cloud: hosted by Obot; free trial then paid; limits set by plan; enterprise auth and support.
- Licence keys validated against Obot's licence service at startup and every 24 hours; exceeding limits or losing a
  valid licence restricts new users/devices/enterprise auth providers but does not delete data.
- No public price list found (obot.ai/pricing/ returned 404 on 2026-10-20).
